# GSAEB Roadmap

Mobile-first, zero-cost hosted roadmap for a fresher backend + AI-integration path.

## What is included

- 16-week curriculum focused on hiring-relevant backend and AI-integration skills
- 3 pacing modes:
  - Normal Mode (3–4 hrs/day)
  - Busy Mode (90 mins/day)
  - Exam Compression continuity protocol
- Today view with daily tasks
- Weekly roadmap view
- KPI dashboard
- Internship application tracker
- Interview prep tracker
- GitHub Pages auto-deploy workflow

## Local run

Open `index.html` directly in a browser.

## Deploy

Push to `main`; GitHub Actions deploys to GitHub Pages automatically.
